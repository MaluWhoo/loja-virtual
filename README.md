## 💡 Sobre o Desafio e Conceitos Aplicados

Este projeto tem como objetivo principal consolidar os fundamentos do desenvolvimento moderno com **Angular** e **TypeScript**, aplicando conceitos essenciais da arquitetura de componentes e reatividade. Durante o desenvolvimento, exploramos:

* **Componentes e Arquitetura Modular:** Organização lógica da interface em componentes reutilizáveis e independentes.
* **Data Binding:** Comunicação eficiente entre a camada visual (Template) e a lógica de negócios (Typescript) utilizando interpolação, property binding, event binding e two-way data binding.
* **Serviços e Injeção de Dependência:** Centralização de regras de negócio, lógica de estado e comunicação HTTP.
* **Consumo de API:** Integração com a [Fake Store API](https://fakestoreapi.com/) para obtenção dinâmica de dados de produtos e categorias.
* **Rotas (`Angular Router`):** Navegação fluida e estruturada entre as diferentes páginas e funcionalidades da aplicação.
* **Formulários Reativos e Validação:** Utilização de `ReactiveFormsModule` e `Validators` customizados para garantir a integridade dos dados inseridos pelos usuários.



## 🛠️ Módulos e Funcionalidades da Aplicação

Abaixo está o acompanhamento do status de desenvolvimento de cada módulo do nosso e-commerce:

- [x] **Catálogo de produtos favoritos:** Seção dedicada para marcar e visualizar itens favoritos, acompanhados de anotações personalizadas.
- [x] **Comparador de preços:** Ferramenta com filtro por categorias reais da API e o espaço analítico "vale a pena?".
- [x] **Painel de estoque fictício:** Gestão simulada de inventário com controle e reposição de estoque em tempo real.
- [ ] **Lista de desejos (Wishlist):** Funcionalidade com adição manual de itens e definição de prioridades validadas por `Validators`.
- [ ] **Mini e-commerce / Carrinho simples:** Carrinho gerenciado por serviço global e formulário de finalização de pedido totalmente validado.
- [ ] **Avaliador de produtos:** Sistema interativo de avaliação por notas (1 a 5 estrelas) e campo de comentários.
- [ ] **Catálogo por categorias e "Tenho interesse":** Listagem categorizada com a opção de registrar interesse no produto acompanhado de observações.
